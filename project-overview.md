# Project Overview — Industrial Energy Monitoring Dashboard

## Summary

This project provides a vendor-neutral dashboard framework for monitoring industrial electrical energy consumption. It includes CSV templates, a Python reference implementation for aggregation and visualisation, a sample dataset of fictional readings, and a Power BI build guide.

## Audience

The package is intended for plant engineers, energy managers, and maintenance planners who need a simple, reusable way to analyse energy consumption data from multiple meters without committing to a specific vendor's analytics tool.

## Scope

The package covers data ingest, aggregation, anomaly flagging, and visualisation. It does not cover tariff calculations, power quality, real-time monitoring, or billing.
