# Components and Bill of Materials — Industrial Energy Monitoring Dashboard

This is a software-only project. The "BOM" is the software stack:

| Component | Version | Status | Notes |
|---|---|---|---|
| Python | 3.8+ | IMPLEMENTED | Required |
| pandas | ≥1.3 | IMPLEMENTED | Data manipulation |
| matplotlib | ≥3.4 | IMPLEMENTED | Chart generation |
| Power BI Desktop (optional) | 2.x | PROPOSED | Alternative visualisation |

No hardware is required to run the reference implementation. The reference implementation is portable across operating systems that support Python 3.8+.
